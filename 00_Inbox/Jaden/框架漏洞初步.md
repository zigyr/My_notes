##### Spring Framework 在 JDK 9+ 上的数据绑定远程代码执行漏洞（CVE-2022-22965）

https://github.com/vulhub/vulhub/tree/master/spring/CVE-2022-22965

运行在 JDK 9 及更高版本上的 Spring MVC 或 Spring WebFlux 应用程序可能存在通过数据绑定（Data Binding）导致的远程代码执行（RCE）漏洞。

该特定漏洞的利用需要应用程序以 WAR 包的形式部署在Tomcat 上。

如果应用程序是以 Spring Boot 可执行 JAR 包的形式部署的（即默认部署方式），则不会受到此漏洞的攻击。

然而，该漏洞的本质更为普遍，可能存在其他利用方式

### Fastcgi协议功能模块漏洞

CGI：是 Web Server 与 Web Application 之间数据交换的一种协议 

FastCGI：同 CGI，是一种通信协议，对比 CGI 提升了5倍以上性能 

PHP-CGI：是 PHP（Web Application）对 Web Server 提供的 CGI 协议的接口程序 

PHP-FPM：是 PHP（Web Application）对 Web Server 提供的 FastCGI 协议的接口程序，额外还提 供了相对智能的任务管理功能
