# Linux `/proc/<pid>` 进程信息速查手册

## 一、概述

`/proc` 是 Linux 内核提供的伪文件系统（procfs），并非普通磁盘目录，用于向用户空间暴露系统及进程的运行信息

`/proc/<pid>/` 对应一个进程，`<pid>` 为进程 **ID（PID）**，可以通过其中的文件查看进程的启动参数、环境变量、内存映射、文件描述符等信息

> **线程（Thread）：** 一个进程可以包含多个线程，每个线程有自己的线程 **ID（TID）**
>
> 线程信息位于 `/proc/<pid>/task/<tid>/`，其中 `<tid>` 为线程 ID
>
> 主线程的 TID 通常与进程 PID 相同
>
> 例如：
>
> ```text
> /proc/
> └── 1806/                 # PID：进程 ID
>     ├── cmdline
>     ├── environ
>     ├── maps
>     └── task/             # 线程目录
>         ├── 1806/         # TID：主线程
>         ├── 1807/         # TID：工作线程
>         └── 1808/         # TID：工作线程

**核心用途：** 在 Linux 信息收集与权限提升过程中，通过 `/proc` 分析高权限进程的运行环境，寻找潜在的信息泄露和权限配置问题

## 二、常用接口速查

| 文件 / 目录 | 含义           | 主要用途                     |
| ----------- | -------------- | ---------------------------- |
| `cmdline`   | 启动命令及参数 | 查看程序启动方式、脚本路径   |
| `environ`   | 环境变量       | 查找敏感变量、凭据           |
| `exe`       | 实际执行文件   | 确认进程执行的程序           |
| `cwd/`      | 当前工作目录   | 查看进程所在目录             |
| `root/`     | 进程根目录     | 判断 chroot 等隔离环境       |
| `maps`      | 内存映射       | 查看加载的程序、动态库       |
| `status`    | 进程状态       | 查看 UID、GID、Capabilities  |
| `stat`      | 进程统计信息   | 查看进程状态、父进程等       |
| `fd/`       | 文件描述符目录 | 查看进程打开的文件、网络连接 |
| `task/`     | 线程目录       | 查看进程包含的线程           |

## 三、常用命令

假设目标 PID 为 `1806`

| 操作           | 命令                                     |
| -------------- | ---------------------------------------- |
| 查看启动参数   | `cat /proc/1806/cmdline`                 |
| 查看环境变量   | `cat /proc/1806/environ \| tr '\0' '\n'` |
| 查看执行文件   | `ls -l /proc/1806/exe`                   |
| 查看工作目录   | `ls -l /proc/1806/cwd`                   |
| 查看进程根目录 | `ls -l /proc/1806/root`                  |
| 查看内存映射   | `cat /proc/1806/maps`                    |
| 查看进程身份   | `cat /proc/1806/status`                  |
| 查看打开的文件 | `ls -l /proc/1806/fd/`                   |
| 查看线程列表   | `ls /proc/1806/task/`                    |

## 四、重点接口说明

### 4.1 environ：环境变量

```bash
cat /proc/<pid>/environ | tr '\0' '\n'
```

- 查看进程启动时继承的环境变量
- 可能包含数据库密码、Token、代理配置等敏感信息
- 环境变量以 `\0` 分隔，因此使用 `tr` 转换为换行符方便阅读

### **4.2 maps：内存映射**

```shell
cat /proc/<pid>/maps
```

查看进程的虚拟内存映射

重点关注：

- 加载了哪些动态链接库
- 是否存在异常的可执行内存区域
- 程序实际映射了哪些文件

权限标记：

| 标记 | 含义     |
| ---- | -------- |
| `r`  | 可读     |
| `w`  | 可写     |
| `x`  | 可执行   |
| `p`  | 私有映射 |
| `s`  | 共享映射 |

### **4.3 fd：文件描述符**

```shell
ls -l /proc/<pid>/fd/
```

查看进程当前打开的文件描述符

例如：

```shell
0 -> /dev/null
1 -> /var/log/cron.log
2 -> /var/log/cron.log
3 -> /var/lib/cron/data
```

常见编号：

- `0`：标准输入 stdin
- `1`：标准输出 stdout
- `2`：标准错误 stderr

还可以发现进程正在使用的文件、管道和 Socket

### **4.4 exe：执行文件**

```shell
readlink /proc/<pid>/exe
```

查看进程实际执行的程序路径

即使原始可执行文件被删除，进程仍在运行时，也可能通过该接口访问其执行文件

### **4.5 cwd 与 root**

| 接口   | 含义               |
| ------ | ------------------ |
| `cwd`  | 进程当前工作目录   |
| `root` | 进程视角下的根目录 |

例如：

```shell
cwd  -> /home/zigyr
root -> /
```

注意：

- `su`：通常保留原工作目录
- `su -`：通常切换到目标用户的家目录
- 切换用户不会自动改变进程的根目录

如果 `cwd` 与 `root` 指向不同位置，属于正常情况；如果两者相同，需要考虑 chroot 等特殊环境

## **五、PID 与 TID：进程和线程**

线程信息位于：

```
/proc/<pid>/task/
```

查看线程：

```
ls /proc/<pid>/task/
```

例如：

```
1806
1807
1808
```

每个数字代表一个线程 ID（TID）

每个线程目录也包含 `maps`、`fd`、`status` 等接口，因为同一进程中的线程通常共享地址空间、文件描述符等资源

| 对象 | 路径                      | 含义                   |
| ---- | ------------------------- | ---------------------- |
| 进程 | `/proc/<pid>/`            | 进程级信息             |
| 线程 | `/proc/<pid>/task/<tid>/` | 线程信息及共享资源视图 |

## **六、Linux 提权中的应用**

当发现一个高权限进程（例如 root 运行的计划任务），可以尝试从 `/proc` 获取运行时信息

推荐排查顺序：

```shell
# 1. 查看进程启动命令
cat /proc/<pid>/cmdline

# 2. 查看执行文件
ls -l /proc/<pid>/exe

# 3. 查看工作目录
ls -l /proc/<pid>/cwd

# 4. 查看环境变量
cat /proc/<pid>/environ | tr '\0' '\n'

# 5. 查看打开的文件
ls -l /proc/<pid>/fd/

# 6. 查看加载的动态库
cat /proc/<pid>/maps

# 7. 查看进程权限
grep -E 'Uid|Gid|Groups|Cap' /proc/<pid>/status
```

**排查目标：**

1. 找到实际执行的脚本或程序
2. 检查脚本、工作目录是否存在普通用户可写的情况
3. 检查环境变量是否暴露敏感信息
4. 检查打开的文件及 Socket
5. 检查动态库加载路径是否存在不安全配置
6. 确认进程实际运行身份及权限

注意：`/proc` 各接口有独立的访问控制，能读取进程目录不代表能读取其中所有内容

## **七、核心记忆**

| 关键词       | 对应接口  |
| ------------ | --------- |
| 执行了什么   | `cmdline` |
| 环境变量     | `environ` |
| 执行文件     | `exe`     |
| 当前在哪里   | `cwd`     |
| 根目录是什么 | `root`    |
| 加载了什么   | `maps`    |
| 打开了什么   | `fd`      |
| 具有什么权限 | `status`  |
| 有哪些线程   | `task`    |

**一句话总结：** `/proc/<pid>` 是观察 Linux 进程运行状态的重要入口，尤其适合在权限提升的信息收集阶段，用来分析高权限进程的执行环境
