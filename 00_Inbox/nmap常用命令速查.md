# Nmap 常用命令速查

## 常用扫描流程

以下示例以授权靶机 `192.168.56.115` 为例

```shell
# 主机探测
nmap -sn 192.168.56.1/24 --min-rate 1000

IP=192.168.56.115

# 端口探测+漏洞扫描
nmap -A $IP -oN nmap.txt -p `nmap -sS -sU -p- -Pn $IP --min-rate 8888 | grep '/tcp\|/udp' | awk -F '/' '{print $1}' | sort -u | tr '\n' ','`
```

## 1. 基础语法

``` bash
nmap [扫描类型] [选项] <目标>
```

目标写法：

``` bash
nmap 192.168.56.115                 # 单个 IP
nmap 192.168.56.1/24                # 网段
nmap 192.168.56.115-120             # IP 范围
nmap 192.168.56.115,192.168.56.120  # 多个目标
```

## 2. 常用场景命令

### 2.1 主机发现

``` bash
nmap -sn 192.168.56.0/24             # 只发现存活主机，不扫描端口
nmap -sn -PR 192.168.56.0/24         # 本地以太网常用 ARP 发现
nmap -sn -PE 192.168.56.0/24         # ICMP Echo 发现
nmap -Pn 192.168.56.115              # 跳过主机发现，直接扫描目标
nmap -n -sn 192.168.56.0/24          # 不做 DNS 解析
```

### 2.2 TCP 端口扫描

``` bash
nmap 192.168.56.115                  # 默认扫描常见 TCP 端口
nmap -sS 192.168.56.115              # TCP SYN 半开放扫描（常用，通常需较高权限）
nmap -sT 192.168.56.115              # TCP Connect 扫描
nmap -p 22,80,443 192.168.56.115     # 指定端口
nmap -p 1-1024 192.168.56.115        # 指定端口范围
nmap -p- 192.168.56.115              # 全部 TCP 端口（1–65535）
nmap -F 192.168.56.115               # 快速扫描常用端口
nmap --top-ports 100 192.168.56.115  # 扫描排名靠前的 100 个端口
```

### 2.3 UDP 端口扫描

``` bash
nmap -sU 192.168.56.115                 # UDP 扫描
nmap -sU --top-ports 100 192.168.56.115 # UDP 常用端口
nmap -sU -p 53,123,161 192.168.56.115   # 指定 UDP 端口
```

TCP 与 UDP 是不同协议。`-p-` 默认指全部 TCP 端口，不代表全部 UDP 端口

### 2.4 服务、版本与系统识别

``` bash
nmap -sV 192.168.56.115                # 探测服务及版本
nmap -sC 192.168.56.115                # 执行默认 NSE 脚本
nmap -O 192.168.56.115                 # 尝试识别操作系统
nmap -A 192.168.56.115                 # 综合探测：OS、版本、默认脚本、路由追踪
nmap -sV -sC -p 22,80 192.168.56.115   # 对指定端口做版本与默认脚本探测
```

`-A` 不代表全端口扫描；需要全端口时另加 `-p-`

### 2.5 扫描速度与重试

``` bash
nmap -T4 192.168.56.115                 # 使用较快的时间模板
nmap -T3 192.168.56.115                 # 默认时间模板
nmap --min-rate 1000 192.168.56.115     # 尝试维持最低发包速率
nmap --max-rate 500 192.168.56.115      # 限制最大发包速率
nmap --max-retries 2 192.168.56.115     # 限制探测重试次数
```

`-T0` 到 `-T5`，越大通常越快

过高的速率可能造成丢包、漏报或影响目标

速度参数不保证实际扫描速度

### 2.6 输出与结果保存

``` bash
nmap -oN scan.txt 192.168.56.115   # 普通文本
nmap -oX scan.xml 192.168.56.115   # XML
nmap -oG scan.gnmap 192.168.56.115 # Grepable 格式
nmap -oA scan 192.168.56.115       # 同时保存多种格式
nmap -v 192.168.56.115             # 增加输出详细程度
nmap -vv 192.168.56.115            # 更详细
```

## 3. 常见端口状态

| 状态               | 含义                                   |
| ------------------ | -------------------------------------- |
| `open`             | 端口上有应用程序接受连接或数据         |
| `closed`           | 端口可达，但没有应用程序监听           |
| `filtered`         | 探测被过滤，无法确定开放或关闭         |
| `unfiltered`       | 端口可达，但无法判断开放或关闭         |
| `open\|filtered`   | 无法区分开放与被过滤，UDP 扫描中较常见 |
| `closed\|filtered` | 无法区分关闭与被过滤                   |

注意：UDP 的 `open|filtered` 不能直接当作已确认开放

## 4. 参数速记
| 参数 | 用途 |
|---|---|
| `-sn` | 只做主机发现 |
| `-Pn` | 跳过主机发现 |
| `-n` | 不做 DNS 解析 |
| `-sS` | TCP SYN 扫描 |
| `-sT` | TCP Connect 扫描 |
| `-sU` | UDP 扫描 |
| `-p` | 指定端口 |
| `-p-` | 全部 TCP 端口 |
| `-F` | 快速扫描 |
| `--top-ports N` | 扫描常用的 N 个端口 |
| `-sV` | 服务版本探测 |
| `-sC` | 默认 NSE 脚本 |
| `-O` | 操作系统识别 |
| `-A` | 综合探测 |
| `-T0`～`-T5` | 时间模板 |
| `--min-rate` | 尝试设置最低发包速率 |
| `--max-rate` | 设置最大发包速率 |
| `--max-retries` | 限制重试次数 |
| `-oN` / `-oX` / `-oG` | 保存为文本 / XML / Grepable |
| `-oA` | 保存多种格式 |
