# Linux - less - 分页查看与搜索

## 高频速记

- f / b  → 整页前进 / 后退
- d / u  → 半页下移 / 上移
- j / k  → 单行下移 / 上移
- g / G  → 文件开头 / 末尾
- n / N  → 下一个 / 上一个匹配
- q      → 退出

## 1. 基本使用

```
less filename          # 分页查看文件
less -N filename       # 显示行号
less -S filename       # 禁止自动换行
less +G filename       # 打开后直接跳到末尾
```

## 2. 常用快捷键

| 快捷键 | 英文来源                      | 含义     | 操作逻辑         |
| ------ | ----------------------------- | -------- | ---------------- |
| `f`    | **Forward**                   | 向前     | 向下翻一页       |
| `b`    | **Backward**                  | 向后     | 向上翻一页       |
| `k`    | **K**（Vim 风格方向键）       | 向上     | 向上移动一行     |
| `j`    | **J**（Vim 风格方向键）       | 向下     | 向下移动一行     |
| `d`    | **Down**                      | 向下     | 向下翻半页       |
| `u`    | **Up**                        | 向上     | 向上翻半页       |
| `g`    | **Go**                        | 前往     | 跳转到文件开头   |
| `G`    | **Go to End**（常见记忆方式） | 前往末尾 | 跳转到文件末尾   |
| `n`    | **Next**                      | 下一个   | 下一个搜索匹配项 |
| `q`    | **Quit**                      | 退出     | 退出 less        |

## 3. 搜索与筛选

| 快捷键     | 功能           |
| ---------- | -------------- |
| `/keyword` | 向下搜索关键词 |
| `?keyword` | 向上搜索关键词 |
| `n`        | 下一个匹配项   |
| `N`        | 上一个匹配项   |
| `&keyword` | 仅显示匹配行   |

## 4. 其他操作

| 快捷键   | 功能                   |
| -------- | ---------------------- |
| `v`      | 使用默认编辑器打开文件 |
| `=`      | 查看文件信息及当前位置 |
| `F`      | 实时跟踪文件更新       |
| `Ctrl+C` | 停止实时跟踪           |
| `h`      | 查看帮助               |

## 5. 常用场景

```
# 查看配置文件并显示行号
less -N wp-config.php

# 查看日志末尾
less +G access.log

# 查看长行，不自动换行
less -S access.log

# 查看文件后搜索密码
less -N config.php
/password

# 搜索下一个匹配项
n

# 退出
q
```
