





- 新进入一个项目，待构建完成
- 随后，在 `app/kotlin+java/com.example.jetpackcomposemissionandroid` 下添加 Package，`com.example.jetpackcomposemissionandroid.jetpackcompose`
- 在新的 Package 中，添加 Kotlin File，命名为`TextExample`
- 随后即有基础 Demo：

```kotlin
package com.example.jetpackcomposemissionandroid.jetpackcompose
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.tooling.preview.Preview

@Preview
@Composable
fun TextExample(){

    Text(
        text = "hell, zigyr"
    )
}
```

在右上角的分屏出，点击即可进行预览
