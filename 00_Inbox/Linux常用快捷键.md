# Linux 常用快捷键与提效技巧

本文整理 bash（Ubuntu 等大多数 Linux 发行版的默认 shell）中的常用快捷键与提效技巧，覆盖历史搜索、命令复用、行内编辑、sudo 重定向陷阱、大括号扩展、进程挂起与别名，均可直接在终端验证

## 历史搜索与命令复用

### `Ctrl+R`：反向搜索历史

按 `Ctrl+R` 进入反向搜索模式，边打字边在整个命令历史中匹配，最近的匹配立刻出现

注意事项：

- 不是想要的匹配：再按 `Ctrl+R` 跳到更早的一条
- 回车直接执行；按右箭头先把命令放上命令行，修改后再执行

### `sudo !!`：以 root 重跑上一条

`!!` 代表上一条命令

忘加 `sudo` 导致权限拒绝时，不用重打整条命令：

```bash
sudo !!
```

注意事项：

- bash 会先打印补全后的完整命令，让你看清实际执行了什么

### `Alt+.`：复用上一条命令的最后一个参数

不用把长路径打两遍

刚对长路径执行过 `ls`，此刻想进入该目录：

```bash
cd <Alt+.>
```

`Alt+.` 会粘贴上一条命令的最后一个参数

注意事项：

- 再按一次，向前循环更早命令的最后一个参数

### `cd -`：跳回上一个目录

`cd -` 回到刚才所在的目录，再执行一次切回去

在项目目录和日志目录之间跳转时，不用再打路径

## 行内编辑

修改已输入的长命令，长按方向键移到行首是最慢的方式：

- `Ctrl+A`：跳到行首
- `Ctrl+E`：跳到行尾
- `Ctrl+W` 或 `Alt+Delete`：删除前一个词

### Ctrl+U / Ctrl+Y：暂存半截命令

长命令打到一半发现得先跑别的，别删

`Ctrl+U` 剪切光标前的内容，bash 会暂存；之后按 `Ctrl+Y`，半截命令就回来了

## sudo 与重定向

用了 `sudo` 仍提示权限拒绝的典型场景：

```bash
sudo echo "10.0.0.5 db" >> /etc/hosts
```

![image-20261111113009969](image-20261111113009969.png)

原因：重定向由当前 shell（无 root 权限）执行，`sudo` 只提权了 `echo`。改用 `tee` 提权写入：

```bash
echo "10.0.0.5 db" | sudo tee -a /etc/hosts
```

![image-20261111112943090](image-20261111112943090.png)

注意事项：

- `-a` 为追加；不加会覆盖原文件

## 大括号扩展

大括号扩展（brace expansion）：一次输入生成一组字符串，由 bash 在命令执行前展开，任何命令都能用

```bash
echo {1..5}        # 1 2 3 4 5
echo {a..e}        # a b c d e
echo {1..100..10}  # 1 11 21 31 41 51 61 71 81 91（步长 10）
touch file{1..10}.txt
rm *.{png,jpg,pdf}
```

## 进程挂起与恢复

程序占满终端时（看日志、编辑器开着文件），不用 `Ctrl+C` 杀掉或另开终端：

- `Ctrl+Z`：暂停程序，拿回提示符
- `fg`：把程序调回前台
- `jobs`：查看全部已暂停的任务

注意事项：

- 有暂停任务时退出 shell，bash 会先警告

## 自定义别名

把常用命令缩短为别名：

```bash
alias ll='ls -lah'
```

注意事项：

- 写入 `~/.bashrc` 末尾才能持久生效，随后 `source ~/.bashrc` 立即加载
- 之后每次开终端别名都在；`type ll` 可验证别名指向
