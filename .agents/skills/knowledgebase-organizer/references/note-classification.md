# Note Classification

## 1. 目录结构

| 目录          | 用途                                   |
| ------------- | -------------------------------------- |
| `00_Inbox`    | 新建及待整理笔记                       |
| `CTF`         | 比赛题目、WP、解题过程和复现记录       |
| `BOX`         | 靶机渗透测试、漏洞利用、提权及攻击路径 |
| `Lesson`      | 课程、教程和学习过程记录               |
| `Environment` | 软件安装、环境搭建、依赖配置和排错     |
| `Knowledge`   | 用户主动沉淀的独立技术知识             |
| `Tools`       | 工具功能、参数、配置和使用方法         |
| `Projects`    | 独立项目和工程实践                     |
| `Reference`   | 速查资料、Payload、命令模板和考点回顾  |

## 2. 分类原则

- 根据笔记主体分类，而不是根据关键词出现次数。
- CTF、BOX、Lesson 保留完整的学习和实践记录，不因包含其他技术知识而自动拆分。
- Knowledge 只收录用户主动决定独立沉淀的知识。
- 不擅自增加一级分类、MOC 或知识图谱。
- 不因笔记数量增加而自动细分目录。

## 3. Lesson 结构

采用「课程 → 教程 → 笔记」结构：

```
Lesson/课程名称/教程名称/笔记主题.md
```

最多三层知识分类层级，资源目录不计入分类层级。

## 4. 分类判断

优先识别笔记的主要目的、记录对象和内容来源。

无法明确判断时，保留原位置并向用户确认，不根据单个技术关键词推测分类。
