# Note Migration

## 1. 迁移对象

每篇 Markdown 笔记与其同级同名资源目录视为一个整体。

例如：

```
BOX/
├── Mr_Robot_渗透测试.md
└── Mr_Robot_渗透测试/
    ├── image1.png
    └── image2.png
```

## 2. 迁移规则

移动或重命名笔记时：

1. 同步处理 Markdown 文件和同名资源目录。
2. 保留原有图片文件及目录结构。
3. 检查 Obsidian 双链。
4. 检查图片相对路径。
5. 确认文件和资源完整。

## 3. 操作限制

- 不单独移动 Markdown 文件而遗留资源目录。
- 不删除资源目录。
- 不擅自集中迁移图片。
- 不修改笔记正文。
- 不擅自覆盖目标文件。
- 发现引用无法正确维护时，停止相关迁移并向用户确认。

## 4. 完成检查

归档后确认：

- Markdown 文件位于正确目录。
- 同名资源目录已同步迁移。
- 图片文件完整。
- Obsidian 双链有效。
- 图片相对路径有效。
- 不存在意外重名或覆盖。
