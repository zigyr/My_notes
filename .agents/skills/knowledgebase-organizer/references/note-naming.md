# Note Naming

## 1. 基本格式

统一使用：

```
主体_内容主题.md
```

CTF 使用：

```
比赛名称_题目名称.md
```

## 2. 命名示例

- `GFCTF_PHP反序列化.md`
- `NSSCTF_ez_php.md`
- `Mr_Robot_渗透测试.md`
- `PHP_反序列化机制.md`
- `Linux_SUID提权.md`
- `Docker_网络配置.md`

## 3. 命名原则

1. 使用半角下划线 `_` 作为分隔符。
2. 前缀体现笔记主体。
3. 后缀直接描述内容主题。
4. 不添加“详解”“全面总结”“基础知识”等无意义修饰。
5. 不将次要技术和环境细节塞入文件名。
6. 同类笔记保持命名一致。
7. 遇到重名先检查内容，不得覆盖。
8. 无法确定名称时保留原名，交由用户确认。
